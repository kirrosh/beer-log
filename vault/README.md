# Vault — как пользоваться

Это Obsidian-вики проекта (паттерн «LLM Wiki» Карпатого: см.
[gist](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)).
Открой эту папку как vault в Obsidian — заработают `[[wikilinks]]` и graph view.

- **[[index]]** — каталог всех страниц.
- **[[log]]** — хронология (ingest/query/lint).
- `raw/` — иммутабельные исходники (агент не правит).
- Остальное (`strategy/`, `product/`, `research/`, `growth/`, `future/`,
  `entities/`) пишет и поддерживает ИИ-агент. Конвенции — в корневом `AGENTS.md`.

Ты отвечаешь за источники, направление и вопросы. Агент — за саммари,
кросс-ссылки и поддержание актуальности.
