# Untappd

Соцсеть чек-инов и оценок пива; де-факто «общая записная книжка» крафтового рынка.
Заблокирован в РФ с **25.04.2026**, без VPN не открывается для рядового потребителя.

## Что с активностью на самом деле (эмпирика 2026-06-04)

Ходили смотреть руками (браузер, без VPN — egress не российский). Блок есть, но
рынок **не «ушёл целиком»**: активность скромная, расслоённая и, вероятно, убывающая
по мере проблем с доступом. Два разных слоя:

- **Tier A — топовые бары ведут ПОЛНОЕ Untappd-for-Business меню.** Пример: Братья
  Крафт (Москва, Ломоносовский 25) — **244 пива** в меню `Tap List` + `Bottles &
  Cans — Russian` (~150) + `Imported` + `Rare & Special` + `Box`. Каждая позиция:
  имя, стиль, ABV, IBU, пивоварня, рейтинг, **формат (`Can`/`Bottle`), объём,
  цена ₽**, срез датирован с точностью до часа (`Wed Jun 03 10:46 PM`), секция
  адресуема через `?menu_id=`. Это **оцифрованный самим заведением холодильник** —
  машиночитаемо тем же `get_page_text`. Источник durable: бар платит за бизнес-меню
  и обновляет его, несмотря на блок.
- **Tier B — длинный хвост без меню, только органический поток чек-инов.** Пример:
  Эрик Рыжий (НН) — ~1–2 чек-ина/день от патронов (не барщика), жив после блока.
  Каждый чек-ин = датированное ребро доступности с форматом. Часть Tier-B кустарно
  имитирует меню масс-чек-инами барщика — то же намерение «опубликовать ассортимент»
  худшим инструментом.

Это **переворачивает** прежнее «RF-бары почти не ведут бизнес-меню» (memory
`untappd-venue-not-demand-source` — верно для хвоста, неверно для топа) и вывод
TASK-31 «холодильник из веба недостижим» (опровергнуто для Tier A).

## Какую ценность он нёс / несёт

- Гости выбирали новинки по оценкам (теперь — кто за VPN).
- Бары следили за реакцией аудитории.
- Пивоварни видели живой фидбэк по сортам.

## Untappd — наш ИСТОЧНИК и апстрим, а не конкурент

Лобовая конкуренция за рейтинг-слой проигрышна: у хардкора там история и соцграф.
Поэтому:

1. **Источник доступности.** Tier A → готовый прайс-лист точки (формат+цена+дата+
   `menu_id`), Tier B → поток чек-инов. Богаче, чем считали. Окно частично закрывается
   (доступ деградирует) → исторический граф RF-венью осмысленно харвестить, пока жив.
   Тулинг: `scripts/ingest-untappd.ts`, `scripts/extract-untappd-cookie.ts`.
2. **Засев персонализации (импорт).** Личный слой ([[personal-tasting-layer]]) не
   просим пере-логировать — *импортируем* оценки/wishlist из Untappd как топливо для
   локатора. Сила Untappd → наш онбординг, а не стена.
3. **Закупочная аналитика для бизнеса.** Остаток ценности (что реально пьют и берут)
   превращаем из публичного рейтинга в [[monetization|платный продукт]] для пивоварен —
   тем сильнее, что у них нет RF-native канала фидбэка. См. [[gtm]], [[phases]].

## Чем мы отличаемся (почему патрону нужны мы, даже когда у бара есть Untappd-меню)

Данные есть, но: (а) за VPN/блоком **в моменте у полки**; (б) покрытие частичное
(только платящие/прилежные бары); (в) нет кросс-венью локатора и «что я не пробовал»;
(г) деградирует. Beer Log = агрегировать это в **no-VPN, кросс-венью, персональный
локатор-в-моменте**. Блок делает ответ Untappd дорогим в моменте — мы делаем его
бесплатным. Ров строим на **доступности+локальности+моменте**, которые переживут
возможное возвращение Untappd. См. [[availability-moat]], [[m4-craft-locator]].
