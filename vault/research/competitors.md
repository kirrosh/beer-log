# Конкуренты — существующие «каталоги» крафта в РФ

Ресёрч 2026-05-29. **Важная поправка (углублённый ресёрг — см. [[need-and-demand]]):**
первоначальный вывод «B2B discovery-аггрегатора нет» оказался неверен. Есть
**РусБир** (rus-beer.ru) — B2B-маркетплейс пива (Москва+МО, импорт/мейнстрим), и
**russiancraftbeer.ru** — работающий реестр крафта по РФ. «Пустой ниши» нет;
defensible только узкий слой нейтральность+аналитика. Подробно: [[need-and-demand]].

## Что нашлось

- **craftopt.ru** — «каталог крафтового пива и оборудования», опт для
  баров/ресторанов/магазинов. Ближе всех к B2B, но это витрина одного оптовика.
- **beerkontora.ru** — магазин (Москва), ~2600 видов. Розница B2C.
- **craftbeer78.ru** — магазин (СПб), 1500+ сортов, есть список пивоварен.
- **wbtraditions.ru** (World Beer Traditions) — крафт оптом для HoReCa и розницы.
- **russiancraftbeer.ru** — каталог крафтовых баров и пивоварен (близко к идее
  реестра, изучить отдельно).
- **bar-beer.ru** — медиа/блог, рейтинги пивоварен.
- **rus-beer.ru (РусБир)** — B2B-маркетплейс: каталог, справочники сортов/
  пивоварен/стилей, сравнение поставщиков, кабинет, API. Ближайший аналог самой
  идеи. Но Москва+МО, фокус импорт/мейнстрим, сам продавец (с 2006).
- **taplist.ru / 4brewers taps** — аггрегаторы кранов; тянули данные из Untappd,
  после блокировки источник сломан.

## Вывод

Существующие игроки — это **продавцы своего ассортимента**, заинтересованные
показать свой склад, а не весь рынок без искажений. Наша позиция — нейтральный
аггрегатор + аналитика спроса, чего у витрин магазинов нет и не будет (конфликт
интересов). Отдельно изучить russiancraftbeer.ru и craftopt.ru как самых близких.
