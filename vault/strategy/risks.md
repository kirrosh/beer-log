# Риски

## Готовность пивоварен платить (главный)
Малые пивоварни считают каждую копейку — продать подписку тяжелее, чем кажется.
Митигация: сначала отдать ценность бесплатно (discovery), платное — аналитика,
которой нет нигде.

> **M2 ([[drift-to-value|решение task-19]] 2026-06-01):** этот риск сдвинут в
> *будущее* — пивоварни больше не платящая аудитория *сейчас*. [[phases|Фаза 0]] =
> открытый справочник для конечного юзера (стоимость ≈ 0, не зависит от выручки);
> готовность платить проверяем позже дешёвым зондом ([[approach]]), без давления.

## Регуляторный (низкий, не нулевой)
ст. 21 ФЗ-38 запрещает рекламу алкоголя для неопределённого круга. Граница (решено
в [[drift-to-value|task-19]]): держим выход **нейтральной рыночной информацией**
(справочник + мета + карта доступности «где найти») — это НЕ продвижение конкретного
продукта/продавца. Чего избегаем: потребительских **рейтингов/чек-инов** и
**«купи здесь»-промо** точки. Открытый доступ при этой рамке — принятый расчётный
риск (прецедент: [[competitors|russiancraftbeer.ru]] открыто показывает наличие).
Аккуратность с формулировками: «мета по рыночным сигналам», не «рейтинг для
потребителя». Связано: [[positioning]], [[mvp-research-mode]].
