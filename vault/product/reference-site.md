# Направление «Dotabuff российского крафта» — открытый справочник + мета

Идея Кирилла (2026-05-29): сделать рейтинг и каталог крафта в формате
Dotabuff / mmorpg.org — справочник + рейтинги/мета + контент, доступ открытый,
часть аналитики прятать, плюс пользоваться самому. Доступ: **открытый** (решено).

## Вердикт: формат — да, «глобально + рейтинг как у Untappd» — нет

Разделяю идею на две части.

**Формат (reference + meta + content) — берём.** Dotabuff/mmorpg.org — эталонный
UX: исчерпывающий справочник + «мета»/рейтинги + контент. Он идеально ложится на
уже выбранный открытый [[mvp-research-mode|ресёрч-режим]] и [[promotion-phase0|контент-движок]],
и ты сам — пользователь №1, что даёт тот самый forcing function, которого
ресёрч-режиму не хватало.

**Глобальный масштаб и «рейтинг» в смысле Untappd — не берём.** Причины ниже.

## Почему не «глобальный каталог всего крафта»

1. **Он уже есть и схлопывается к одному победителю.** Untappd выиграл рынок
   глобальных оценок. RateBeer — 640k сортов, 50k пивоварен, 9,5M оценок, владелец
   AB InBev — **закрылся 01.02.2025.** Если уж RateBeer с таким массивом не выжил,
   глобальный beer-rating как самостоятельная история — тяжёлый winner-take-most,
   куда мы бы вошли без дата-рва.
2. **Нет дата-рва.** Dotabuff работает, потому что Valve отдаёт фид матчей открытым
   API. У пива «матчи» — это чекины/оценки, и они **проприетарны Untappd**, их не
   сбутстрапить. Миллионы чужих оценок не воспроизвести.
3. **Юр-тупик, от которого мы ушли.** Публичный потребительский рейтинг алкоголя
   от лица из РФ — ровно та «реклама для неопределённого круга», которой пугает
   [[gtm|ст. 21]]. Untappd мог — он иностранный, и его всё равно заблокировали
   ([[untappd]]). Повторять этот заход из РФ — назад в грабли.

## Что МОЖЕМ и где новизна

Уточнение про слово «рейтинг»: рейтинги Dotabuff — из *объективных* исходов
матчей; пивные «рейтинги» — *субъективные* пользовательские оценки, источника
которых после ухода Untappd у нас нет (и это самая юр-рискованная часть). Поэтому
не копируем «оценки», а делаем **«мету» из наблюдаемых сигналов**:

- что варят и кто (справочник);
- что в наличии и по каким городам;
- тренды стилей, новинки;
- цены и [[data-model|скидки/уценки как сигнал спроса]].

Это и легальнее (рыночные данные, не потребительский рейтинг), и новее: RF-«мету»
крафта сейчас не показывает никто — это и есть вакуум после [[untappd|ухода Untappd]].

## Рекомендуемая цель

**«Dotabuff российского крафта»:** открытый исчерпывающий справочник RF-крафта +
мета по наблюдаемым рыночным сигналам + контент. Глубокая B2B-аналитика — под
замком (потенциальная монетизация позже, дверь открыта — см. [[monetization]]).

> **Закреплено [[drift-to-value|решением task-19]] (2026-06-01):** это направление —
> основное, аудитория = **конечный пользователь**. Ключевая мета — **карта
> доступности «где найти»** (ров). «Рейтинги» здесь = только мета по рыночным
> сигналам (наличие, охват, тренды, цены/скидки); **user-оценки не делаем**.

- **Открыто:** справочник пивоварен/сортов, мета (тренды, новинки, наличие),
  контент/дайджесты.
- **Скрыто/по запросу:** гранулярная аналитика спроса.
- **Seed данных:** проверено по API (2026-05-29) — **в Open Brewery DB 0
  российских пивоварен** (всего 9 559, в основном США/Европа/Корея/ЮАР; РФ нет
  вовсе, по СНГ — лишь 1 запись в Днепропетровской обл.). И база только
  brewery-level, без сортов/наличия/цен. Вывод: **сид по РФ делаем сами** —
  [[parser-architecture|парсеры]] (TG + магазины) + импорт из существующего реестра
  [[competitors|russiancraftbeer.ru]] и брендовых списков магазинов (craftbeer78,
  craftopt). Open Brewery DB — максимум как референс схемы / «обои» для глобалки
  потом. Бэклог: `task-11`.

## Это не смена курса

Формат/витрина меняется (reference+meta вместо «продукта» или сухого датасета), но
**ядро то же**: парсеры + каталог + дедуп + петля сигналов ([[mvp]]). То есть это
лучшая форма подачи для открытого [[mvp-research-mode|ресёрч-режима]], а не новый
проект.
