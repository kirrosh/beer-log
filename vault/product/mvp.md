# MVP — декомпозиция Фазы 0 и первые шаги

Цель MVP ([[phases|Фаза 0]]): единый discovery-каталог крафта, собранный
полуавтономно из открытых источников, чтобы проверить гипотезу — **ходят ли
байеры смотреть discovery**. Без второй стороны, без транзакций, без ЕГАИС.

## Что входит в MVP (и что НЕ входит)

Входит: сбор данных (парсеры), нормализация и дедуп каталога, витрина для
просмотра (фильтр по стилю/городу, поиск), базовая аналитика заходов, контент
для привлечения. Не входит: профили/онбординг пивоварен (Фаза 1), платная
аналитика (Фаза 2), заказы и ЕГАИС (Фаза 3).

## Декомпозиция на блоки

**1. Сбор данных.** [[parser-architecture|Парсеры]] из Telegram (прототип готов:
`packages/parsers`) и сайтов магазинов/пивоварен. Старт — TG-каналы
([[telegram-sources]]), т.к. ближе всего к Фазе 0 и не требуют API. Бэклог:
`task-1`, `task-2`.

**2. Каталог и дедуп.** Модели в `catalog-core` ([[data-model]]). Нужно
хранилище (SQLite/bun:sqlite) и слияние одинаковых пивоварен/сортов из разных
источников по slug+алиасам. Очередь ручной валидации (статус `auto→validated`).
Бэклог: `task-3`.

**3. Витрина (сайт).** Заменить заглушку `packages/web`: список пивоварен/сортов,
фильтр по стилю и городу, поиск, страница сорта/пивоварни. Bun + TS. Бэклог:
`task-4`.

**4. Аналитика заходов.** Метрики Фазы 0: уникальные байеры, частота возвратов,
какие разделы смотрят. Это и проверка гипотезы, и сырьё для будущей платной
[[monetization|аналитики спроса]].

**5. Привлечение.** [[promotion-phase0|Контент-движок]]: свой TG-канал +
автодайджесты новинок из каталога. Бэклог: `task-6`.

## Критический путь

`task-1` (найти прайсовые каналы) → `task-2` (парсер боевой) → `task-3`
(каталог+дедуп) → `task-4` (витрина) → `task-6` (промо). Параллельно `task-5`
([[parser-architecture|самовосстановление]]) как инфраструктура.

## Первые шаги (эта и ближайшая сессии)

1. Найти 15+ публичных TG-каналов с прайсами/новинками, прогнать парсером.
2. Замерить точность извлечения на ~100 сообщениях, докрутить экстрактор.
3. Поднять SQLite-хранилище + upsert с дедупом.
4. Собрать первую витрину на реальных данных.
5. Завести TG-канал проекта и первый автодайджест.

## Метрики выхода из Фазы 0

>= 50 уникальных байеров в каталоге за первый месяц и заметная доля возвратов →
гипотеза подтверждена, переходим к [[phases|Фазе 1]] (онбординг пивоварен).
