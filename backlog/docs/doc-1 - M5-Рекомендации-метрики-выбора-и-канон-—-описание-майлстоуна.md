# M5: Рекомендации, метрики выбора и канон

## Зачем

Каталог (22K сортов / 266 пивоварен / 14K листингов по 28 продавцам), витрина и бот построены.
Следующий шаг — превратить данные в **реальную помощь при выборе** для одного пользователя (Кирилла),
не показывая чужие отзывы (они субъективны и не дают вэлью). Базовый движок «топ-5 под меня»
(TASK-43) и профиль вкуса (TASK-48) уже есть, но опираются почти только на личный слой,
где пока ~4 дегустации.

## Принцип

Объективной метрики «качества пива» не существует — любая её имитация выродится в чужие отзывы.
Зато честно считаются **три независимые оси**, и рекомендация = их пересечение:

1. **Рыночные метрики из собственной базы** (объективные, ноль новых источников):
   - **Value Index** — ₽/литр против медианы стиля по всем продавцам («−18% к медиане» / «переплата +40%»);
   - **Дистрибуция** — в скольких из 28 продавцов держат сорт = рыночный отбор закупщиков;
     обратный край — «есть только здесь» = редкость;
   - **Персистентность** — сорт, который точка держит месяцами (по seen_at), = её якорь;
     мелькнувший раз = ротация;
   - **Ценовая динамика** — discounted/prev_price: скидка на 🔥-стиль = повод для пуша (смыкается с TASK-9);
   - **Свежесть наличия** — уже есть (tier/provenance), вытащить в причины.

2. **Личная модель вкуса** (главный актив проекта одного пользователя):
   - hit-rate по пивоварне/стилю/дескриптору («Jaws: 3/3 🔥» — личная статистика лучше любого Untappd);
   - ABV-комфорт-зона из 🔥-вердиктов;
   - wouldRepeat=false как жёсткий анти-сигнал («за свои норм» ≠ брать снова);
   - cost-per-🔥 — личная экономика: сколько в среднем стоят мои огоньки;
   - **холодный старт** — узкое место: модель оживает после бэкфилла дегустаций по памяти
     и нулевого трения ввода (TASK-46/47 — критический путь, не «удобство»).

3. **Канон-слой** («что маст-трай») — ось «канонично», а не «понравится мне».
   Не зависит от числа дегустаций → даёт пользу с первого дня, идеален для холодного старта.
   Три типа каноничности:
   - **brewery-flagship** — визитка пивоварни («если у Jaws пробовать одно — что»);
   - **style-benchmark** — эталон стиля, доступный в РФ («понять, что такое гозе»);
   - **ru-classic** — знаковые сорта российского крафта (десятки позиций = долгосрочный чеклист).

   Наполнение без чужих отзывов: каноничность — это **известность** (факт), не оценка:
   чекины Untappd (самый чекиненный сорт пивоварни = визитка), дистрибуция в нашей базе,
   ресёрч-курация (для эталонов стилей и RU-классики). Хранение — data/personal/../canon.json
   (правит агент), highlights.json остаётся редакционным слоем точки и наполняется из канона.

## UX-правила

- **Скор всегда объяснён** — никогда не голая цифра: 2–3 причины по осям
  (вкус / деньги / якорь точки) + честные минусы;
- **Анти-сигналы обязательны** — «у этой пивоварни ты дважды 👎» ценнее ещё одной рекомендации;
  система, которая отговаривает, — половина вэлью;
- **Квота discover** — 1–2 слота из топ-5 всегда вне вкусовой модели (приоритет — незакрытый канон
  с точки), иначе петля самоподтверждения сужает вкус;
- **Замыкание петли** — после «беру» бот сам спрашивает «как тебе X?» назавтра;
  без этого дегустации не копятся и модель мертва;
- **Канон-паспорт** — прогресс «RU-классика: 4/23, визитки: 6/266» превращает размытое
  «надо больше пробовать» в чеклист.

## Чего сознательно НЕ делаем

- Единый «балл качества» пива — нет данных, будет враньё;
- Текстовые отзывы людей как сигнал;
- Блокировка на векторах (TASK-36) — все слои категориальные/арифметические;
- Untappd-рейтинг как главный сигнал — только опциональный прайор с малым весом,
  нормализованный внутри стиля (стауты системно выше IPA), взвешенный log(checkins), отключаемый.

## Состав и порядок ценности

1. Value Index + дистрибуция + персистентность — чистая арифметика по готовым данным, польза сразу;
2. Канон-слой (canon.json → ресёрч → интенты «маст-трай здесь» / «мой канон») — польза с нуля дегустаций;
3. Петля «как тебе вчерашнее» + бэкфилл по памяти — кормят личную модель;
4. Профиль вкуса v2 (hit-rate, ABV-зона, cost-per-🔥, анти-сигналы);
5. Еженедельный дайджест-пуш (дельта листингов × профиль);
6. Untappd-прайор (ut_rating/ut_checkins) — последним, опционален, заодно уточняет канон по чекинам.

Эволюция: сейчас канон тащит рекомендации почти один → после ~50 дегустаций канон закрывает
discover-слоты, вкусовая модель — остальное.
