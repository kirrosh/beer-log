## Description

Публичная витрина открытого ресёрч-режима в формате reference+meta (см.
vault/product/reference-site.md): справочник пивоварен/сортов + «мета» по
наблюдаемым сигналам (тренды стилей, новинки, наличие по городам, цены/скидки) +
контент/дайджесты. БЕЗ потребительских user-рейтингов (источника нет + юр-риск).
Глубокая аналитика — под замком.

## Acceptance Criteria

- [x] Сид пивоварен из RF-источников (russiancraftbeer.ru, списки craftbeer78/craftopt) + парсеры — в Open Brewery DB по РФ 0 записей (проверено по API)
- [x] Публичные страницы: пивоварня, сорт (стиль/город — фасеты на главной)
- [x] Блок «мета»: распределение по стилям, охват городов (из каталога). Новинки/наличие — позже (нужна дата релиза + demand-слой)
- [x] Автогенерируемые дайджесты/контент из вики (LLM-wiki) — гибрид: факты из снапшота + LLM-проза → `/meta`
- [x] Гранулярная аналитика спроса скрыта/по запросу — флаг сборки PRIVATE режет per-seller данные

## Прогресс (v2)

- **2026-06-02:** закрыты последние два пункта AC — задача готова к Done.
  - **Мета-дайджест (LLM-wiki):** разделение труда. `scripts/gen-digest.ts` ДЕТЕРМИНИРОВАН —
    считает ФАКТЫ из снапшота (распределение стилей, топ городов, топ пивоварен/сортов по
    охвату, скидки, провенанс) и собирает `digest.json`; никаких API-вызовов. ПРОЗУ поверх
    фактов пишет **агент Claude Code через скилл `meta-digest`** и кладёт в
    `data/digest-prose.md` (коммитится). Скрипт берёт прозу из файла (`mode=prose-file`),
    иначе fallback на детерминированный шаблон. Флаг `--facts` отдаёт факты скиллу. Новая
    страница **`/meta`** (мета-плашки + stacked-бар стилей + проза + топ-6 по охвату),
    навлинк «Мета».
  - **Гейт гранулярной аналитики:** флаг сборки `PRIVATE=1`. Публичная сборка (дефолт)
    режет per-seller данные на этапе экспорта — `places[].minPrice` (цена по точке) и
    `places[].listedBeers` (сколько сортов марки у продавца) уходят в `null`, флаг
    `snapshot.full=false`. На витрине — плашка «гранулярная аналитика спроса — по запросу».
    Агрегаты (reach, листинги, диапазон цен по сорту, «где найти») остаются открытыми.
    Полная выгрузка: `PRIVATE=1 bun run web:build`.
  - Команды: `bun run digest:gen`; `web:build` теперь = export → digest → build.
    typecheck + статическая сборка зелёные, `/meta.html` пререндерится.
