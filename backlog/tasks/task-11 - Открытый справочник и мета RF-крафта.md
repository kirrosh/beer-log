## Description

Публичная витрина открытого ресёрч-режима в формате reference+meta (см.
vault/product/reference-site.md): справочник пивоварен/сортов + «мета» по
наблюдаемым сигналам (тренды стилей, новинки, наличие по городам, цены/скидки) +
контент/дайджесты. БЕЗ потребительских user-рейтингов (источника нет + юр-риск).
Глубокая аналитика — под замком.

## Acceptance Criteria

- [x] Сид пивоварен из RF-источников (russiancraftbeer.ru, списки craftbeer78/craftopt) + парсеры — в Open Brewery DB по РФ 0 записей (проверено по API)
- [x] Публичные страницы: пивоварня, сорт (стиль/город — фасеты на главной)
- [x] Блок «мета»: распределение по стилям, охват городов (из каталога). Новинки/наличие — позже (нужна дата релиза + demand-слой)
- [ ] Автогенерируемые дайджесты/контент из вики (LLM-wiki)
- [ ] Гранулярная аналитика спроса скрыта/по запросу

## Прогресс (v1)

- **2026-05-29:** собрана тонкая витрина — **SvelteKit + Svelte 5 (runes) + Vite,
  Bun, статичная сборка (`adapter-static`)**. UX-спека: [[reference-site-ux]].
  - Главная: мета-полоса (пивоварни/сорта/города/стили + цветной stacked-бар
    распределения по стилям) + фильтры (поиск, категории-chip, город, ABV, verified,
    офиц. TG) + переключатель `Сорта | Пивоварни` + плотные списки.
  - Страницы `/beer/<slug>` (характеристики, описание-провенанс, источники, соседи)
    и `/brewery/<slug>` (город/сегмент, офиц. ссылки, мини-мета, её сорта).
  - Данные: `scripts/export-catalog.ts` → `packages/web/src/lib/data/catalog.json`
    (никакой БД в рантайме). Команды: `bun run web` (dev), `bun run web:build`.
  - Тёмная «терминал»-эстетика, цвет = категория стиля, кириллица-шрифты. Без
    потребительских рейтингов (рыночные данные, ст. 21).
- Дальше: новинки по дате релиза, demand-мета (цены/наличие — task-10/14),
  автодайджесты из вики (task-6).
