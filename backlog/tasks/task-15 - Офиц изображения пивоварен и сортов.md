## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Добавить в каталог/витрину официальные изображения: логотип пивоварни, изображение
этикетки/банки сорта. Решено (2026-05-29) **отложить** — вернуться, когда база
пивоварен и данные будут полнее.

Подход к реализации — решить при старте задачи (Кирилл склонялся «как-то брать
офиц. изображения»):

- **Предпочтительно: только ссылки** на офиц. источники (URL логотипа с сайта,
  OG-превью, картинка из TG) — без скачивания/рехостинга. Снимает копирайт-риск
  чужого брендового контента. Колонки `breweries.image_url` / `beers.image_url`.
- **Рехостинг** (скачать к себе) — только при явном решении: загрузка файлов +
  правовая чистота брендовых изображений требуют отдельного согласования.
