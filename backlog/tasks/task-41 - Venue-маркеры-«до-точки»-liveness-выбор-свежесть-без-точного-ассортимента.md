## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Сценарий «до точки» (выбор бара — слой НАД локатором холодильника). Даже когда точного ассортимента нет (Tier-B без Untappd-бизнес-меню), дать венью непустую карточку из дешёвых сигналов, решающих «куда идти». Каскад деградации по тиру (принцип «лучше грубо, чем никак»):
- 🟢 живой — свежесть последних чек-инов (Tier-B: главное, что спасает карточку)
- 📦 большой выбор — Offering N (Tier-A) / разнообразие пивоварен в чек-инах (Tier-B, прокси)
- 🔄 ротация/новинки — новые сорта в чек-инах за N дней
- 📰 свежие новости — TG/источники точки (часть уже трекаем)
- 🕐 возраст данных — provenance (observed_at/tier, ср. TASK-35)
- 📍 статус на картах (2ГИС/Яндекс: открыт/рейтинг/популярно) — ПОТОМ, не в первой версии

Бонус Tier-B: лента чек-инов даёт и liveness, И мягкий сигнал ассортимента («здесь недавно видели: …») — карточка без меню всё равно непустая. Тот же скрейп Untappd, что трек E (TASK-38), но тянем ЛЕНТУ чек-инов, а не меню — сиблинг парсера.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Честные рамки: liveness ≠ «X на кране сейчас» — это сигнал ВЫБОРА бара, не истина холодильника. «Большой выбор» из чек-инов — грубый прокси (мало чекинят ≠ мало выбор) → badge. Совпадает с философией availability-moat (низкая планка достоверности + дата = ценность).

Пример: Эрик Рыжий (venue 6310279) — ~22 чек-ина за 2.5 недели, distinct пивоварни Plague/Big Village/Velka Morava/Одна тонна → «живой, ротация». Tier-A (Игра/Hophead/Братья Крафт) — Offering N напрямую.

Под личную оптику (memory pet-project-personal-utility-frame): закрывает «в какой бар в НН идти вечером» — слой до поездки. Сиблинг TASK-38 (тот же fetch, другая страница: лента чек-инов vs меню); отображение — TASK-34; свежесть — TASK-35.
