## Description

Два рыночных сигнала из price_listings без новых источников. Дистрибуция (breadth): в скольких из 28 продавцов есть сорт — рыночный отбор закупщиков; обратный край «есть только здесь» = редкость, аргумент взять сейчас. Оба сигнала в скоринг new-ветки и в человекочитаемые причины. Описание майлстоуна: backlog/docs/doc-1.
