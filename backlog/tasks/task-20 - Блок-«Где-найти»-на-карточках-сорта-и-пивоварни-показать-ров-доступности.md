## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Сейчас вся уникальная ценность (где купить/выпить) лежит в данных (demand: sellers, reach, цены, format), но в UI невидима — карточка сорта показывает только ABV/IBU/стиль/описание. Сделать «Где найти» первоклассным блоком: список продавцов (магазины + бары), цена «от X₽» (розница, опт исключён), пометка разлив/бутылка, дата снапшота. На карточке пивоварни — агрегат охвата. Это делает позиционирование «не Untappd, а где взять» осязаемым.

РАЗМОРОЖЕНА: task-19 закрыта (2026-06-01) — первичная аудитория = конечный юзер, «Где найти» показываем ОТКРЫТО как нейтральную рыночную информацию о доступности. Форма блока подтверждена (продавцы + цена «от» + разлив/бутылка + дата снапшота); user-рейтинги не добавляем. Это анкор-фича рва M2.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Реализовано 2026-06-01.

**Данные (`scripts/export-catalog.ts`):** добавлен классификатор `sellerKind` (shop /
bar = `t.me/*` / opt = `OPT_SELLERS`). В `beer.demand` добавлено поле `places[]`
(per-seller: kind, minPrice, formats[], discounted, seenAt); в `brewery.demand` —
`places[]` (per-seller: kind, listedBeers). Существующие агрегаты (reach/listings/
minPrice — их читает `/top`) не трогали. Розничная цена теперь исключает не только опт,
но и **кег** (30л — не потребительская розница), что заодно чистит грязный `maxPrice`
(известная проблема из log.md).

**Типы/хелперы (`packages/web/src/lib/catalog.ts`):** `SellerKind`, `Place`,
`BreweryPlace`; экспортируемые презентационные хелперы `fmtPrice`, `plur`,
`sellerLabel`, `SELLER_KIND_LABEL`, `formatLabel` (переиспользуют обе карточки).

**UI:** карточка сорта `/beer/[slug]` — блок «Где найти» сразу после характеристик
(продавец + бейдж тип + форматы + «от X₽»/«разлив»/«опт» + дата + note). Карточка
пивоварни `/brewery/[slug]` — компактный агрегат (reach + чипы продавцов с числом
сортов) после офиц. ссылок. Подача — «рыночная информация о доступности», без
«купи здесь» (рамка `vault/strategy/legal-boundary.md`).

**Проверка:** `bun run typecheck` (0), `svelte-check` (0 ошибок/предупр.),
`bun run web:build` — полный пререндер 17k+ карточек зелёный; блок подтверждён в
пререндеренном HTML.
