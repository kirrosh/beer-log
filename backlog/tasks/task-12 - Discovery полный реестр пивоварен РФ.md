## Description

Слой 1 (см. vault/product/sourcing-strategy.md). Приоритет Фазы 0 — полнота
справочника. Собрать максимально полный список пивоварен РФ + их официальные
ссылки (сайт/VK/TG), не полагаясь ни на один источник. Источники: полный обход
russiancraftbeer (пагинация /list, /gorod/*, страницы /brewery со ссылками и
сортами), брендовые списки магазинов (craftopt, craftbeer78, beerkontora),
profibeer. Реестр — только для обнаружения (кто есть + где офиц. канал), не как
источник правды (данные устаревшие, 2017).

## Acceptance Criteria

- [ ] Полный обход russiancraftbeer (пагинация /list + города + /brewery)
- [ ] Импорт брендовых списков из 2-3 магазинов
- [ ] >= 200 пивоварен с городом и хотя бы одной офиц. ссылкой
- [x] Дедуп с существующими записями (slug/алиасы)

## Подход (уточнён 2026-05-29 по факту разведки)

«Реестр + магазины» (решение Кирилла). НО разведка показала:
- **russiancraftbeer.ru/export сломан** — отдаёт HTML Drupal, `parseRcbExport` → 0
  (плюс данные 2017 г.). Реестр как несущий источник вширь — нет.
- **Магазины** серверные, но **без чистого индекса производителей** (бренды
  размазаны по карточкам) — нужен per-shop crawl, хрупко.

Поэтому исполняем устойчиво (как уже сработало дважды): **агентная разведка** —
агенты компилируют и верифицируют **активных** пивоварен с офиц. ссылками; магазины
подключаем точечно за ценами/наличием там, где карточки парсятся.

**«Активна» =** живой офиц. канал (свежие посты) ИЛИ присутствие в текущих каталогах
магазинов. Закрытые/без признаков жизни — не берём (помечаем).

## Прогресс
