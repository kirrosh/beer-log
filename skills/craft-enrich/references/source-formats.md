# Форматы источников (Telegram-first)

Справочник форматов сырья для обогащения. Читать, когда нужно разобрать конкретный
источник.

## 1. Релиз новинки из канала пивоварни (лучший источник характеристик)

Публичное превью: `https://t.me/s/<handle>` (без API-ключа). Пост-релиз обычно
имеет структурный заголовок: название, стиль, строка `Алк % / Plato / IBU`, затем
описание и хэштеги.

Пример (Rewort, @RewortBrewery):
```
Hazy shade of summer
IPA - New England / Hazy
Алк 6.5% / Plato 16.5% / IBU 25

<описание…>
#rewort #сергиевпосад
```

Якорь для парсинга — строка ABV/Plato/IBU:
`Алк\s*([\d.,]+)\s*%\s*/\s*Plato\s*([\d.,]+)\s*%?\s*/\s*IBU\s*([\dNA/]+)`
Две непустые строки выше якоря = `styleRaw` (ближняя) и `name` (через одну).
Описание = непустые строки ниже до первого хэштега/ссылки.

Готовая функция: `parseBreweryReleases(text)` в `packages/parsers/src/telegram/rewort-release.ts`.
Формат заголовка стабилен у многих российских пивоварен; если у конкретной
пивоварни иначе — подправь якорь и проверь на 3–5 постах, прежде чем массово гнать.

**Важно:** web-fetch отдаёт превью как текст/markdown (не сырой HTML). Боевой
`telegramWebParser` работает по сырому HTML (`t.me/s/...`, класс
`tgme_widget_message_text`) — он для прогона на машине; для разбора web-fetch-текста
используй `parseBreweryReleases` по строкам.

## 2. Канал магазина / боттлшопа (наличие, цены, новинки)

Те же `t.me/s/<handle>`. Формат свободный: позиции «Пивоварня — Сорт, стиль, ABV,
объём — цена ₽», списки новинок, остатки. Извлечение цен/стиля — эвристический
`extractFromMessage` (`packages/parsers/src/telegram/extract.ts`): цена
`(\d[\d\s]{0,7})\s?(₽|руб|р\.|rub)`, ABV `(\d{1,2}([.,]\d)?)\s?%`, объём `мл/ml`,
формат (кег/банка/бутылка/разлив), стиль через `categorizeStyle`.

## 3. Витрина сайта магазина (структурные карточки)

Самый чистый сигнал спроса. У каждого магазина своя разметка; общий приём — карточка
товара даёт имя + цену (₽), часто объём, иногда ABV/цвет и остаток.

Наблюдённые примеры:
- **craftbeer78.ru** (`/brewery/<slug>`): `[<цена> ₽ <Название> - <Пивоварня>](url)`,
  иногда `**<N> шт**` = остаток.
- **winestyle.ru** (`/beer/<brand>-beer/craft/`): карточка с `Крепость: X %`,
  цветом (`Тёмное/Светлое/Янтарное`), ценой, `по 12 шт` = опт. Имена часто
  транслитом/по-английски (см. дедуп).

Подводный камень: один сорт называется по-разному в разных магазинах (рус. vs
транслит) → нужен fuzzy `isSameBeer` + ручные алиасы.

## 4. Сайт пивоварни

Часто лендинг без каталога (как rewort.ru), но даёт ссылки на TG/VK/Untappd и
контакты. Полезен для офиц. ссылок и подтверждения города/типа пивоварни.

## 5. Реестры (discovery, не источник правды)

`russiancraftbeer.ru` (`/export`, `/brewery/<slug>`): список пивоварен, их офиц.
ссылки и (устаревший, ~2017) список сортов. Парсер `parseRcbExport`. Только для
обнаружения «кто есть + где офиц. канал».

## Здоровье источников (наблюдения)

Источники хрупкие: магазины ложатся (craftopt — InSales-заглушка), часть на JS
(greatbeer/beeribo — нужен браузерный рендер), Untappd заблокирован, реестры
устаревают. Отсюда правило: много источников + провенанс, ни один не несущий.
